How a match runs
  1. Enter a display name and create a room.
  2. Send the invitation link to one friend on any device.
  3. The host picks a round length. Both players mark ready.
  4. The server starts the clock and accepts sticker sends.
  5. Most accepted stickers when time runs out wins.

Tapping the send control repeatedly works. Holding it repeats sends at the same rate the server allows. The score you see always comes from the server.
