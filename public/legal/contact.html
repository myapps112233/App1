Privacy and deletion requests

Rooms expire automatically and all room state is lost when the server restarts, so most information disappears without action. If you are writing about a specific match, include:

  • The room code, if you still have it.
  • The display name you used.
  • The approximate date and time of the match, including the time zone.

Do not send identity documents, passwords, or payment information. The game does not have accounts, so a request may not be actionable once the room has expired. Requests are reviewed and answered where the operator can reasonably identify the data.

Personal records

Your personal best is stored only in your browser and is not held by the operator. To remove it, use the button on the Cookie Preferences page or clear site data in your browser.

Security reports

If you find a security issue, report it privately through the contact method above with enough detail to reproduce it. Do not test against other players' rooms, run load tests against the public deployment, or access data that is not yours.

Asset licensing

The sticker collection served by a deployment is supplied by the operator of that deployment. If you believe an image is used without permission, contact the address above with the image identifier shown in the sticker file name and the deployment address so it can be reviewed and removed if necessary.
