Cookie Preferences

Effective {{EFFECTIVE_DATE}}

This version of Sticker Showdown sets no cookies. It does not use analytics, advertising, or third-party tracking scripts. Because only essential functionality and browser storage are used, the game does not show a consent banner: there is nothing optional to consent to.

1. Browser storage used by the game

These entries are stored by your browser and are never sent to the server as a whole.

  • sticker-showdown:record:v1 in local storage. Holds your personal best score, the display name of the opponent in that match, and the round length. It stays until you clear it or clear browser data.
  • sticker-showdown:name:v1 in local storage. Holds the display name you typed, so the field is filled the next time you open the game on this device.
  • sticker-showdown:session:v1 in session storage. Holds the room code and a random session token for the current browser tab so a refresh can reconnect you to the same player slot. It is removed when the tab closes or when you leave the room.

Your live score is held on the server while a match runs. It is not written to your browser during the round.

Contact details for the operator of this deployment: {{CONTACT}}. See the Privacy Policy for the full description of processing and retention.

2. Removing the stored data

The button below removes the local record and the saved display name from this browser. It cannot be undone.

You can also clear this data with your browser settings, usually under privacy or site data. Blocking local storage is allowed. The game still runs, but it cannot keep a personal best or remember your name.

3. Server-side and hosting data

The server holds temporary room state in memory and writes operational logs. The hosting provider may set strictly necessary infrastructure cookies at the platform level. These are controlled by the provider, not by the game, and are not used for advertising. See the Privacy Policy for details.

4. If this changes

If optional cookies, analytics, or advertising are added later, this page will be updated and a working consent mechanism will be required before those features are activated in regions that require consent. A banner will not be displayed without functioning controls.
