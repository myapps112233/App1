# Sticker asset notice

These sticker images were supplied by the owner of this repository for use in this
deployment of Sticker Showdown. They are personal reaction images.

Before making the game public, the repository owner must confirm that they hold the
right to publish and distribute every image here. Stickers taken from messaging apps
(for example WhatsApp sticker packs) are frequently not licensed for redistribution,
even when they are easy to download. Availability of a file is not a licence.

If you replace this collection:

1. Put authorized WebP, PNG, or JPEG files in this directory.
2. Keep files under 2 MB (the server rejects larger files).
3. Regenerate the catalogue with `npm run manifest`, or edit
   `manifest.json` to add descriptive alt text.
4. Record the source and licence for each image below.

## Format notes

The original uploads were 512x512 WebP files. They were resized for fast mobile
playback and two animated files (STK-20261017-WA0002.webp and
STK-20261024-WA0008.webp) were reduced to their first frame, because 40 to 64 frame
animations at ten sends per second are too heavy for low-end phones. Replace them and
regenerate the manifest if animated stickers are wanted.

The untouched originals are kept in `assets/source-stickers` for reference. They are
not served by the game.
